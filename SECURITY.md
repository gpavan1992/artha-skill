# Security and support

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue:

1. Open https://github.com/gpavan1992/artha-skill/security/advisories/new (the *Security* tab, then *Report a vulnerability*)
2. Describe what you found and how to reproduce it

Artha is a one-person open-source project. Reports are handled on a best-effort basis, and fixes ship as a new release noted in `CHANGELOG.md`.

**In scope:** the scripts, the `SKILL.md` instructions, the GitHub workflow, and anything that could leak your files or run unexpected code.
**Out of scope:** wrong or delayed numbers from a data provider. Use the *Data source broke* issue template for those.

## Support
